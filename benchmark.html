Consistency Test

The same question + same uploaded copy + same evaluator version should produce the same stored benchmark result. The ×10 test calls the evaluator repeatedly and reports whether the returned score is identical across all runs.

Methodology & disclosure

Blind: candidate identity, topper status and coaching name are not included in the evaluator prompt. Fairness: presentation is assessed for readability and examiner attention risk; marks are not randomly reduced because of simulated fatigue. Visuals: diagrams/maps/flowcharts are checked for relevance, labels, accuracy, readability and integration. Disclosure: FATEH27 evaluation is AI-based and is not an official UPSC evaluation. Coaching/institute names are used only to identify public benchmark sources and do not imply endorsement.
